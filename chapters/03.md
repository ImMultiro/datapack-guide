Now that you know what a data pack is and have your workspace set up, it's time to finally create your first data pack. In this chapter you will learn about the
structure of a data pack, how to make one and activate it in-game, as well as how to use some basic commands. Before we begin, however, create a new Minecraft
world if you haven't already. It should be a creative-mode world with `Allow Commands` set to `ON` - this will be our test world for the remainder of this guide,
so it should be easy to run commands for testing.

## Locating the `datapacks` directory
First thing you should know is that, unlike mods, which modify your Minecraft client and can directly affect the entire game, data packs are placed in a world,
meaning they can only affect that world. Because of that, if you want to load a data pack into a world, you first need to find that world's `datapacks` directory
(or folder). To do so, you need to follow these steps:
1. Open *File Explorer* (or a similar app if you're not using *Windows*)
2. Type one of the following into the adress bar, depending on your operating system:

| OS          | Path                                      |
|-------------|-------------------------------------------|
| **Windows** | `%APPDATA%\.minecraft`                    |
| **MacOS**   | `~/Library/Application Support/minecraft` |
| **Linux**   | `~/.minecraft`                            |

3. Open the `saves` directory
4. Find your world and open its directory
5. Open the `datapacks` directory

You will be using this directory a lot, so it might be a good idea to pin it to Quick Access or elsewhere you can find it easily.

## Creating a new data pack
To create a data pack, simply create a new folder called `Learning Data Pack` in the `datapacks` directory. You can use *VS Code*'s "Open Folder" feature to open
your data pack. To do that, press Ctrl+K. Some text should appear in the bottom-left corner of the screen saying **(Ctrl+K) was pressed. Waiting for second key of
chord...**. After that, press Ctrl+O. A folder selection window should open - navigate to your data pack directory and press "Select Folder".
